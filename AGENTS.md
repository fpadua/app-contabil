# Instruções do projeto

## Skills obrigatórias

Antes de iniciar qualquer implementação neste projeto:

1. Use a skill `$minha-skill`.
2. Leia completamente o arquivo `SKILL.md` da skill antes de alterar arquivos.
3. Aplique os padrões, arquitetura e convenções definidos pela skill.
4. Caso alguma instrução da skill entre em conflito com este arquivo, siga o `AGENTS.md`.
5. Antes de finalizar, execute as validações e verificações definidas pela skill.

## Fluxo de trabalho

- Analise a estrutura existente antes de criar arquivos.
- Preserve os padrões já utilizados pelo projeto.
- Não adicione dependências sem informar.
- Execute os testes relacionados às alterações.
- Informe quais arquivos foram alterados.
